# 🍕 AI Pizza Chatbot

A web-based Pizza Chatbot developed using Flask, HTML, CSS and Python.

---

## 📌 Project Overview

This project is a chatbot application designed for pizza ordering and customer support. Users can interact with the chatbot to view menu items, check prices, place orders, and get restaurant information.

---

## 🎯 Features

- Interactive Chat Interface  
- Pizza Menu Information  
- Price Details  
- Order Placement  
- Delivery Information  
- Restaurant Location Details  
- User-Friendly Design  

---

## 🛠 Technologies Used

- Python  
- Flask  
- HTML  
- CSS  
- JavaScript

## 🚀 How to Run

### 1. Install required libraries
```bash

```

### 2. Run the project
```bash
python app.py
```

### 3. Open in browser
http://127.0.0.1:5000
